RouteX 3.4.5 — route check and leak fixes

- Route window: no more "Unknown" for apps that go through a VLESS / VMess / Trojan tunnel. Checking an app without a domain, live connections whose domain is not known (browsers with Secure DNS / DoH) and a domain without an app now get a real route; the reason says which domain rule could still send that site elsewhere. "Unknown" is left only for rules with ports / TCP-UDP filters that the check cannot see.
- Configs tunnel (VLESS / VMess / Trojan): the local SOCKS port of the tunnel now requires a random per-run password, and its unused HTTP port is gone. Before, any program on the PC (including apps in Exclude that scan localhost for proxies) could send traffic through the VPN and learn its exit IP. Subscriptions / system proxy ports are unchanged.
- VPN Only: when the VPN is down, the kill switch now blocks Include apps as well as Strict VPN apps (in VPN Only they have no DPI fallback, so they used to go out directly with the real IP).
- Kill switch never blocks RouteX itself or its cores (wiresock-client, xray, sing-box, winws), even if a list entry matches their path.

Fully disconnect the VPN and close RouteX before replacing the executable. RouteX.exe and NetProbe.exe are identical.
