NetProbe 3.3.4 — Route window shows the real route for VLESS / VMess / Trojan tunnels
## Fix: Route window for VLESS / VMess / Trojan tunnels
- With a VLESS / VMess / Trojan tunnel (xray + sing-box TUN) the Route window checked routes by WireGuard (WireSock) rules, which know only apps. Domains and IPs in Exclude / Include were ignored there, so e.g. an excluded `youtube.com` was shown as "→ VPN" although sing-box sent it direct.
- Now the Route window uses the same rules, in the same order, as the running sing-box config: NetProbe's own processes → direct; Exclude apps / domains / IPs → past the tunnel (DPI or direct); Include domains / IPs and Include apps → tunnel; everything else → past the tunnel. Live connections in the window use the same logic.
- Tip: excluding a site's main domain does not exclude its CDN. For YouTube, video comes from `googlevideo.com` — add it to Exclude too if videos should bypass the tunnel; the Route window now shows this correctly.
