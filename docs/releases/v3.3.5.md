NetProbe 3.3.5 — Routing shows the real tunnel engine (VLESS / VMess / Trojan)
## Fix: Routing always said "WireSock"
- The status line on the Routing page always showed `WireSock «…»`, even when the selected tunnel in VPN configs is VLESS / VMess / Trojan. It now shows the engine of the tunnel that is actually running (or selected, when not connected): `VLESS · xray «…»`, `VMess · xray «…»`, `Trojan · xray «…»` or `WireSock «…»` for WireGuard.
- "WireSock not found" warnings (Routing page, start log, failed connect reason) now appear only when the primary or enabled backup tunnel is WireGuard — a VLESS / VMess / Trojan setup does not need WireSock.
- When an xray tunnel exits, the log says `xray TUN: tunnel exited` instead of `WireSock exited`.
